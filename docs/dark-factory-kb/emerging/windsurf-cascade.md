## Mechanism notes (Cascade era)
- **Cascade:** In-editor agent with codebase awareness, multi-file edits, terminal commands, “flow awareness” (watches edits/terminal/clipboard).
- **Positioning then:** AI-native VS Code fork competing with Cursor; agentic pair programmer more than async mill.
- **After Cognition:** Editor becomes agent command center; cloud Devin + local Devin Local share harness direction; Cascade kept briefly as fallback / JetBrains plugin option per admin settings coverage.
