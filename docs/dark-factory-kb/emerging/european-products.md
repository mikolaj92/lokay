# European products (sovereignty / governance skew)

**Archetype:** Often C→E *with* EU AI Act / audit emphasis, or EU-hosted agent infra.  
**Caveat:** Several are early / marketing-heavy — verify traction before weighting.

## NeuroCOD (neurocod.eu)
- Self-described **AI Software Factory** with autonomous release + **EU AI Act** compliance packaging (model registry, risk levels, kill switch, FRIA flags).
- “10/10 maturity” domain scorecard marketing; governance + factory learning narrative.
- URL: https://neurocod.eu/

## Autonoma (theautonoma.io)
- Governed autonomous SDLC: BUILD / OPERATE / SECURE / PLATFORM; **29 specialized agents**; **RIGOR** framework (Research, Inspect, Generate, Optimize, Review) + audit trails; EU AI Act / ISO 42001 alignment claims.
- Closest *European product language* to Guild-style specialized-agent factories.
- URL: https://www.theautonoma.io/

## orkestr (orkestr.eu)
- **EU-hosted** infra for apps + agent **workers** + **sandboxes** (microVMs); scoped agent identity; approval gates for irreversible actions; audit trails; Slack reporting.
- Data centers DE/FI/FR narrative — sovereignty substrate for someone else’s mill.
- URL: https://orkestr.eu/

## Cerebe (cerebe.ai)
- PRD→production agentic SDLC; **Software Factory** gate with adversarial multi-vendor review quorum; separation of duties (writer ≠ approver); FastAPI+Next+Helm ownership claims.
- URL: https://cerebe.ai/

## orq.ai
- Sovereign **agent lifecycle** platform (orchestration, evals, observability, governance, gateway across many providers) — more control plane than coding mill.
- URL: https://orq.ai/

## Magic.dev
- See [magic-dev.md](./magic-dev.md) — European founders, SF lab; listed here for geography, product-thin.

## Dark-factory distance
**Autonoma / NeuroCOD / Cerebe** pitch E-with-governance. **orkestr** is the sandbox/worker substrate EU teams may prefer over US cloud agent VMs. Expect heavier approval gates → *more* human limbo by design (compliance), which is still “serious eng org” structure.
