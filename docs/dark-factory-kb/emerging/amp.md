# Amp (ampcode.com) — Sourcegraph spinout

**Archetype:** Interactive → remote agent (B→C)  
**Note:** Distinct from legacy **Cody** (Sourcegraph enterprise assistant).

## Mechanism notes
- **Amp:** “Frontier agent” for agentic workflows — VS Code-compatible editors, CLI, web, phone. Threads can run in **orbs** (remote machines that keep working after laptop closes).
- **Team/multiplayer:** Share threads; plugins hook events/tools/policy (Pi-inspired).
- **Model stance:** Moves with frontier models; aggressive deletion of stale UX (“delete old workflows”).
- **Pricing (docs):** Megawatt / Gigawatt subscriptions include agent + orb minutes; pay-as-you-go credits at provider rates (no markup claimed for non-enterprise); Enterprise +50% with SSO, admin, retention, MCP allowlists, etc.
- **Cody split:** Cody remains enterprise-focused coding assistant on Sourcegraph search context; consumer Cody Free/Pro directed to Amp. Sourcegraph doubles down on code search/understanding; Amp as independent agent lab.

## Dark-factory distance
**Mid.** Orbs enable AFK issue-shaped work, but product is still developer-centric agent threads, not an out-of-box ticket mill with janitors/merge bots. Can be *wired into* a mill.
