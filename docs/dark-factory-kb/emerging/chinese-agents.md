# Chinese AI coding agents / IDEs (2025–2026)

**Archetype mix:** Mostly B→D (agentic IDEs + Quest-style autonomy); enterprise plugins with compliance skew.

## Notable entries

### ByteDance Trae (+ MarsCode legacy)
- Positioning: AI-native IDE; SOLO/Builder-style autonomous full-stack modes; MarsCode folded in as plugin lineage.
- Domestic free tiers / aggressive model access reported in 2026 roundups.
- URLs: search Trae IDE / ByteDance; MarsCode agent research paper lineage for autofix.

### Alibaba Qoder (ex-Tongyi Lingma)
- Standalone **agentic IDE** (Aug 2025 → 1.0 early 2026 narrative); Agent Mode (interactive) + **Quest Mode** (autonomous multi-step → tested feature).
- Multi-model routing; credit-based pricing; “AI employee” / % of company code narratives in secondary sources.
- Closest CN analog to Cursor+Devin hybrid inside one IDE.
- URL pattern: qoder.ai / Alibaba Cloud Tongyi Lingma docs historically.

### Zhipu / Z.ai — CodeGeeX + ZCode
- CodeGeeX: long-running IDE plugin, open weights history (CodeGeeX4 etc.).
- **ZCode (2026):** “ADE” (agentic development environment) — chat/agent-centric desktop aggregating CLI agents; private deploy / GLM model family (e.g. GLM-5.2 in mid-2026 coverage).
- Strong for visual multi-agent management + compliance-sensitive private deploy.

### Tencent CodeBuddy / WorkBuddy
- Plugin/enterprise angle; Hunyuan pairing; compliance / 等保-style private deployment as moat in CN reviews.

### Moonshot Kimi Code
- Long-context / agentic coding emphasis (Kimi K2/K3-class); API + plans — model-led more than full factory OS.

### DeepSeek (+ Harness / DSH)
- Frontier cheap models (V4 Pro/Flash class in 2026 coverage); **DeepSeek Harness** open-sourced as agent workflow research surface (MIT, trajectory features) — OSS mill substrate interest.

### Baidu Comate
- Multimodal AI IDE / wide editor coverage; China enterprise distribution.
